# @-/com.npmjs.modelcontextprotocol__sdk

Workspace wrapper for `@modelcontextprotocol/sdk`, the official MCP TypeScript SDK.

## Usage

Import the upstream exports through `@-/com.npmjs.modelcontextprotocol__sdk`.

## API

`McpServer`, `Server`, `StreamableHTTPServerTransport`, `CallToolRequestSchema` and `ListToolsRequestSchema`, and the `CallToolResult` type.
