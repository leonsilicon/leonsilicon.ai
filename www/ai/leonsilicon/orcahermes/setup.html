Install OrcaHermes

Set up an always-available Orca server on your own Hermes instance.

What you need

  • A shell on a managed Hermes Linux host, as the account that runs Hermes.
  • Linux x86-64 or arm64, Python 3.12 or newer, Bash, and curl.
  • A persistent /opt/data mount and the writable Hermes s6 service tree.
  • Orca on your computer and a Tailscale admin who can configure MagicDNS, HTTPS, and access rules.

This installer checks the host before registering services. For a self-hosted Hermes deployment with a different service manager, use Orca’s service setup.

1. Install on the Hermes host

Run this in a shell on the host. The installer verifies the publisher’s checksums and places Orca, Tailscale, and Codex under /opt/data/orcahermes. It uses the existing service manager to start Orca and the private network daemon at boot. 

installer=$(mktemp) &&
curl --proto '=https' -fsSL https://orcahermes.leonsilicon.ai/install.py -o "$installer" &&
python3 "$installer" install

Download the installer source

2. Connect your private network

In the Tailscale admin console, enable MagicDNS and HTTPS. Add the tag:orcahermes device tag and give your Orca users access to it only on TCP port 16768. Merge these entries into your tailnet policy and replace the example account with your own. 

{
  "tagOwners": { "tag:orcahermes": ["autogroup:admin"] },
  "grants": [{
    "src": ["you@example.com"],
    "dst": ["tag:orcahermes"],
    "ip": ["tcp:16768"]
  }]
}

Tailscale rules are additive. Narrow any broader rule that covers this device, since userspace networking can forward other listening ports when policy grants access. Tailscale grants

Pick a unique lowercase name for this host. Open the Tailscale sign-in link printed by the command and authorize the tagged device. If sign-in times out, rerun the command to finish setup. 

python3 /opt/data/orcahermes/orcahermes.py network my-orcahermes

The command prints the private TLS endpoint after Tailscale Serve is configured. Tailscale Serve documentation

3. Pair an Orca client

Generate the pairing link in your private shell. The command briefly restarts Orca to issue the offer and waits for the supervised service to return. 

python3 /opt/data/orcahermes/orcahermes.py pair

On your computer, connect to the same tailnet. In Orca, go to Settings → Remote Orca Servers → Add Server and paste the link. Choose a display name for the server, connect, and add a project from the host. Orca pairing documentation

4. Sign in to Codex if you use it

Follow the device sign-in instructions printed by Codex on the host. Then open a fresh Orca terminal on the remote server and run codex login status. 

python3 /opt/data/orcahermes/orcahermes.py codex

Verify your setup

Check both services and the local Orca request, then open a terminal on the paired host. The host keeps its own projects and sessions under /opt/data. 

python3 /opt/data/orcahermes/orcahermes.py status

If a service fails to start, read its rotating log under /opt/data/orcahermes/logs. Re-running the installer resumes an incomplete setup. An unrecognized OrcaHermes installation is left in place.

Teach Hermes about OrcaHermes

Add the skill to the Hermes profile you use to manage this host. It explains which service to check, how to verify private access, and where to find the installation guide. 

hermes skills install leonsilicon/leonsilicon.ai/packages/com/leonsilicon/hermes/skills/orcahermes
