OrcaHermes

A reference for running Orca independently on the Nous-hosted Hermes instance.

Service responsibilities

Headless Orca server
Owns the remote projects, workspaces, terminals, and agent sessions.
Orca supervisor
Restarts the Orca runtime and lets the replacement reconnect to a surviving terminal daemon.
Platform service manager
Starts the Orca supervisor at boot and replaces it if it exits unexpectedly.

Deployment verification

The headless server runs on Nous under Orca’s built-in supervisor and s6. A live terminal survived both a runtime crash and a supervisor crash. After a full Nous restart, Orca and its private connection returned automatically. The paired client reached the same project, and Codex resumed a signed-in session from persistent storage.
