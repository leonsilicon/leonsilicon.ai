Overview Server Supervisor Platform

Platform service manager

The platform manager starts the Orca supervisor and watches the supervisor process.

Boot and shutdown

The Nous-hosted image uses s6 to manage services. Orca’s foreground supervisor runs as a service in the existing Hermes service tree and uses a persistent profile. A Hermes gateway startup hook restores the service registration. The service manager handles supervisor failure and rotates the service logs.

Verification

Service registration and local runtime startup were verified on Nous. Automatic startup, persistent pairing identity, and private client access after a full host restart remain unverified. A platform restart ends live terminal processes, so an agent session must resume from durable state afterward.
