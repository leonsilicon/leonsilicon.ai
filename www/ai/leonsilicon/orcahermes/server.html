Headless Orca server

The server owns the workspace and executes terminal and agent work on the machine that hosts it.

Clients and workspaces

Paired clients connect over a private network and receive revocable Orca access. Repositories, worktrees, terminal state, and provider sign-ins belong to the server profile. The private connection and the HTTPS certificate for these reference pages are configured separately.

Codex is installed on the server and uses a server-side provider sign-in. A paired desktop can disconnect while the server continues working.

Verification

The deployed server answered a local project-list request, registered a repository on persistent storage, and created a live terminal. A paired device listed projects over a private connection with a valid TLS certificate. Orca rejected an unauthenticated request. A signed-in Codex session resumed after interruption and recalled context from its first turn.
