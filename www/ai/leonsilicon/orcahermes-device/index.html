OrcaHermes Device Agent stack

OrcaHermes Device

Connect Hermes Cloud to existing Orca installations on paired Macs.

How it connects

Hermes launches the orca MCP tool server over standard input and output. The Linux Orca CLI uses its saved pairings to reach the selected Mac over a private Tailscale link. The Macs host the workspaces and run the commands.

Deployment

The runbook covers building and installing a release on Hermes Cloud. The service documentation describes the pairing store, network link, and MCP tools.
