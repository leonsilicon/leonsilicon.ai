slack22linear

Keeps Linear issues and Slack conversations in sync, with one Slack channel per issue.

How it works

The Worker verifies Slack Events API and Linear webhook signatures, then queues the work. A Cloudflare Durable Object processes jobs one at a time, records issue-to-channel and comment-to-message mappings, and retries failed work.

Issue channels follow Linear status in Leon’s Slack sidebar. Linear’s own Slack integration creates project channels. AutoLinear can hand off a channel it already created to the same sync queue.

Setup

  1. Connect the integrations. Install the slack22linear Slack bot and enable Linear’s official Slack integration with Project channels on. Subscribe the bot to message.channels, message.groups and reaction_added at /slack/events.
  2. Configure credentials and routes. Set the #slack22linear values in the environment schema for the Linear API key, webhook secret, Slack bot token, signing secret, Slack session, and admin token. Point the Linear Issue, Comment, and Project webhook to /linear/webhook on the same Worker.
  3. Deploy and verify. Check /healthz. Create a test issue and confirm its channel, then add a comment in each direction. The runbook includes an authenticated backfill for existing issues.
    vpr -w deploy:slack22linear
