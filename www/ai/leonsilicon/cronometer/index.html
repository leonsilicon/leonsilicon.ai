How it works

A Python Worker wraps the unofficial cronometer-mcp connector, which talks to Cronometer’s mobile API. The Worker stores the upstream session in Cloudflare KV to avoid signing in for each request.

The tools can look up foods and read the diary, as well as add, edit, or delete entries. The public health check reports Worker availability. An authenticated call to get_profile checks the Cronometer connection.

Setup

To connect an authorized client, add a Streamable HTTP MCP server at this URL. Set the Authorization header to Bearer <token> using the token issued by the operator.

https://cronometer.leonsilicon.ai/mcp
  1. Configure your own deployment. Use the #cronometer group in the environment schema. Set your Cronometer login and CRONOMETER_HTTP_TOKEN in Infisical, and set the public hostname and KV binding for your Worker.
  2. Build and deploy. Install the repository toolchain and uv for the Python dependencies. Run the command below from the repository root, then connect your client and call get_profile.
    vpr -w deploy:cronometer
