Gmail Feed

Mirrors Leon’s incoming Gmail into Slack, with separate channels for flagged messages and spam.

How it works

A Cloudflare Durable Object polls Gmail history and queues new messages in SQLite. Gmail spam goes straight to the spam feed. Other messages go through safety and urgency checks using OpenAI before the feed bot posts them.

Slack receives the message as plain text with a link back to Gmail. Attachments stay in Gmail. Messages that pass screening can mention Hermes when they meet the configured urgency threshold.

Setup

  1. Authorize Gmail. Enable the Gmail API in your Google Cloud project and authorize an OAuth client with the gmail.readonly scope. Obtain a refresh token for the mailbox you want to mirror.
  2. Configure delivery. Install the feed bot and add it to the flagged and spam channels. Set the Google OAuth credentials, Slack bot token and channel IDs, OpenAI API key, Hermes user ID and admin token in the #gmail-feed group of the environment schema. Set GMAIL_FEED_WAKE=none for a silent feed.
  3. Deploy and confirm delivery. The first poll records a starting point. Send a test email and check the Slack feed. Use the runbook’s authenticated backfill command to import older mail.
    vpr -w deploy:gmail-feed
