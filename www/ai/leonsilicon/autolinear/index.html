AutoLinear

Turns eligible Slack messages to Hermes into Linear issues and gives each conversation a dedicated Slack channel.

How it works

A signed Slack event can start intake as soon as Leon sends a message. The Hermes plugin also calls POST /intake when Hermes handles it. Both paths use the same message ID, so concurrent requests and retries share one result.

The Worker creates an issue in Awaiting Init, opens a channel and copies the message there. It edits the original to link to the new channel, then slack22linear manages the channel. Hermes replies there, or answers in place if intake fails.

Every turn Hermes finishes in an issue channel ends with a line for the Autolinear bot, such as @Autolinear move done, @Autolinear move leon or @Autolinear stay. Only that line moves the issue. When a turn ends without one, Autolinear reminds Hermes, twice at most, then tells Leon. Leon can give the same commands with /autolinear.

Setup

  1. Configure the Worker. Clone the repository and install its toolchain with vp install. Use the relevant group in the environment schema to configure Infisical for your Worker. Set the #autolinear values for Linear, the Slack session, the intake token and Slack signing secret. Deploy slack22linear first so its channel handoff is available. Then deploy AutoLinear from the repository root.
    vpr -w deploy:autolinear
  2. Connect Slack. Install the AutoLinear Slack app with the channels:history and im:history user scopes. Subscribe to message.channels and message.im at https://autolinear.leonsilicon.ai/slack/events, or the same path on your Worker. Give the app a bot user with chat:write, reactions:write and commands, and point the /autolinear command at /slack/commands. slack22linear holds the bot's token and user ID.
  3. Enable Hermes. Install the AutoLinear plugin, set AUTOLINEAR_TOKEN and AUTOLINEAR_USER_ID, and keep the Slack puppet guard enabled. Set AUTOLINEAR_URL to your Worker’s /intake if you use a different hostname. Send Hermes a test message outside an issue channel to verify the setup.
