Grok Bot Admin

Lets authorized Grok Bot agents list the account’s bots and clean up helpers they no longer need.

  1. Grok BotAccount-wide MCP configuration

How it works

The Worker uses a dedicated Cursor sign-in to reach Grok Bot’s backend. It keeps the session in Cloudflare KV and refreshes it as expiry approaches.

Use grok_bots_list to fetch bot IDs and names. grok_bot_delete removes a bot by numeric ID or agent ID. Deletion is permanent and includes the bot’s conversations, memory, routines, and attachments.

Setup

Add grokbot-admin as a Streamable HTTP MCP server in the Grok Bot account configuration. Set Authorization to Bearer <token> using the token issued by the operator.

https://grokbot-admin.leonsilicon.ai/mcp
  1. Configure your own deployment. Set GROK_BOT_ROSTER_MCP_TOKEN and your public origin using the #grok-bot-roster group in the environment schema. Set up the Worker’s STATE KV binding.
  2. Authorize and verify. Deploy, then follow the Cursor sign-in steps to seed the KV session for your account. Check /healthz and use grok_bots_list to test the connector.
    vpr -w deploy:grok-bot-roster
