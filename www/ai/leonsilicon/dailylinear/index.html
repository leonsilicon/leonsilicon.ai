DailyLinear

Starts each Toronto day with a fresh Linear project and a starred Slack channel, then closes out past days.

How it works

A single Cloudflare Durable Object coordinates scheduled and manual runs. It finds or creates the day’s Linear project, asks Linear’s Slack integration for its channel, then renames it to #project-YYYY-MM-DD, invites Hermes and stars it for Leon.

The same run completes past daily projects and archives their channels. If the channel is still being provisioned or a request fails, the Worker retries.

Setup

  1. Connect Linear and Slack. Install Linear’s Slack integration with Project channels enabled. Choose the Linear team where the daily projects belong.
  2. Configure the Worker. Clone the repository and install its toolchain with vp install. Use the relevant group in the environment schema to configure Infisical for your Worker. Use the #dailylinear group for the Linear API key and team, Slack session, Hermes user ID and admin token.
  3. Verify the first run. Deploy, then wait for the schedule or call POST /admin/run with the DAILYLINEAR_ADMIN_TOKEN bearer token. Check for the dated project and its Slack channel.
    vpr -w deploy:dailylinear
